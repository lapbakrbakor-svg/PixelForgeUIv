Learn

Make your first UI in 5 steps

  1. Press Create UI. You start with an empty ScreenGui.
  2. Press Insert and add a Frame. Drag it, or pull its handles to resize.
  3. Pick it in Explorer and change its color in Properties.
  4. Insert a UICorner while the Frame is selected to round its corners.
  5. Press Export Luau, copy the script into a LocalScript in StarterPlayerScripts.

Shortcuts

Ctrl+Z undo · Ctrl+Y redo · Ctrl+D duplicate · Del delete · arrows nudge 1px (Shift 10px) · Alt while dragging skips snapping · Esc cancels a drag

Good to know

The browser preview approximates Roblox. Fonts, text scaling and list-layout alignment can differ in-game. Export recreates structure and visuals only, not button logic. Test in Studio before shipping.
